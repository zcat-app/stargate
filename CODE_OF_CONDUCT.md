# Code of Conduct

Stargate adopts the [Contributor Covenant version 2.1][covenant]. Its complete
terms are incorporated here by reference and apply in project spaces and when
someone officially represents the project.

Report conduct incidents privately through the repository's
[GitHub Security Advisory form][report]. Put `Code of Conduct report` in the
summary. Maintainers will protect reporter privacy as far as the investigation
allows, evaluate reports promptly and fairly, and apply consequences consistent
with the Contributor Covenant's enforcement guidelines.

Do not file a public issue containing personal or sensitive incident details.
If the reporting form is unavailable, ask for a private contact channel in a
public issue without disclosing the incident.

This adoption is based on the Contributor Covenant, version 2.1, available
under the Creative Commons Attribution 4.0 license.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[report]: https://github.com/zcat-app/stargate/security/advisories/new
