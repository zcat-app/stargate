### Major

#### B1. Closed-vocabulary `detail` gate false-passes when DP echoes the offending value
- **Worklist file**: `redteam/findings/open/20260706-002-detail-rejected-echo-false-pass.md` (status: fixed-pre-merge, fix-commit 417ca54)
- **Where**: `tests/contract/control-grpc/watch_events_test.go` — `assertDetailRejected`
- **What**: See worklist file. A DP logging `rejected event detail="could not bind 0.0.0.0:9050"` would pass both the stream-close and `journalHasDetailViolation` assertions while leaking the offending sidecar free text into the journal — the precise leak the closed-vocabulary gate exists to prevent.
- **Implicates**: Constitution Principle III (logs contain no per-request/secret bytes) and Principle VII (the test is the executable guarantee). Contract `control-grpc.md` §"WatchEvents · Contract" closed-vocabulary clause.
- **Remediation (applied)**: `assertDetailRejected` now calls `findSecretLeaks(h.journal.String(), []byte(detail))` and fails on any hit, inheriting the multi-encoding coverage (hex / base64 x4 / decimal-slice / decimal-run).

### Minor

#### M1. Plaintext `%q` in failure messages
- **Where**: `socks5ConnectReply` auth-failure `t.Fatalf`
- **What**: Interpolated the auth plaintext via `%q` into CI logs on the auth-failure path. The plaintext is the one secret in scope; failure output lands in CI logs.
- **Remediation (applied)**: Removed the `%q` interpolation; the byte index is sufficient to diagnose.

#### M2. Hash+salt not in the leak-scan set
- **Where**: `HappyPathTransitionsRouteToEnabled` + `DisconnectReconnectAppliesEvents` — both called `mintToken(t, plaintext)` inline, so the generated hash and salt were never captured into a variable and could not be passed to `assertNoSecretLeak`. Both sub-tests scanned only `[]byte(plaintext)`.
- **What**: A DP logging the loaded snapshot's hash/salt via a startup log path would be missed. Low-likelihood (the WatchEvents consumer itself doesn't touch tokens) but a narrowing of T020's hygiene for no functional reason.
- **Remediation (applied)**: `tok := mintToken(t, plaintext)` is now captured and `assertNoSecretLeak(t, h, tok.GetHash(), tok.GetSalt(), []byte(plaintext))` matches T020's discipline.
