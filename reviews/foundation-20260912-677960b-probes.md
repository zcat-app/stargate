## Production Java client deadline aging

The successful probe used Java source-file execution with the classpath from
`java.class.path` in
`control-plane/api/target/surefire-reports/TEST-io.quarkus.stargate.control.grpc.InterPlaneWireTest.xml`.
The baseline Maven verification supplies those compiled production classes.
Create synthetic CP/DP Ed25519 PKCS#8/SPKI files in a temporary directory,
then run the following class against that directory. No server is needed:
the finding is expiration before the first RPC, not proof of a live-server
revocation failure. Delete the synthetic files afterward.

```java
import io.grpc.*;
import io.quarkus.stargate.control.grpc.*;
import java.nio.file.*;
import java.security.*;
import java.util.*;
import java.util.concurrent.*;
class DeadlineProbe {
  public static void main(String[] a) throws Exception {
    Path d=Path.of(a[0]);
    for(String name:List.of("cp","dp")) {
      var k=KeyPairGenerator.getInstance("Ed25519").generateKeyPair();
      Files.writeString(d.resolve(name+".priv"),"-----BEGIN " + "PRIVATE KEY-----\n"+Base64.getEncoder().encodeToString(k.getPrivate().getEncoded())+"\n-----END " + "PRIVATE KEY-----\n");
      Files.writeString(d.resolve(name+".pub"),"-----BEGIN PUBLIC KEY-----\n"+Base64.getEncoder().encodeToString(k.getPublic().getEncoded())+"\n-----END PUBLIC KEY-----\n");
    }
    try(var c=ReloadTokensClient.create(d,d.resolve("absent.sock"))) {
      var f=ReloadTokensClient.class.getDeclaredField("stub");
      f.setAccessible(true);
      var stub=(io.grpc.stub.AbstractStub<?>)f.get(c);
      var deadline=stub.getCallOptions().getDeadline();
      System.out.println("initial deadline remaining sec="+deadline.timeRemaining(TimeUnit.SECONDS));
      Thread.sleep(11000);
      System.out.println("before first reload expired="+deadline.isExpired());
      try { c.reload(1,List.of()); }
      catch(StatusRuntimeException e) { System.out.println("first reload="+e.getStatus().getCode()); }
    }
  }
}
```

Observed: initial remaining seconds 9, expired before first call true,
first call `DEADLINE_EXCEEDED`.
